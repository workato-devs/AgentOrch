# Support

Use GitHub issues for reproducible bugs and documentation problems. Include
the command, Python version, operating system, backend, recipe ID, and the
smallest sanitized error excerpt that demonstrates the problem.

Use GitHub Discussions, when enabled, for setup questions, result
interpretation, and ideas that are not yet actionable bug reports. Questions
about a provider's account, billing, model access, or service availability
belong with that provider.

Never post credentials, private URLs, proprietary model outputs, or
organization data. Follow [`SECURITY.md`](SECURITY.md) for vulnerabilities or
suspected data exposure.
